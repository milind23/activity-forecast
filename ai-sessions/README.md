# AI/work trail

This submission should be described as **human-led and AI-assisted**, not
"human-only." The exercise asks for AI use, and inventing a human-only history would be
misleading.

back-dated. Commit history and a polished narrative do not prove human judgment; the useful
chain is requirement/assumption → decision → diff → verification → correction.

## Candidate review gate

Before making the repository public, the candidate should:

1. Export or link the actual 2026-10-15/16 chat if the tool supports it.
2. Review every decision in [NOTES.md](../NOTES.md) and edit anything they do not agree
   with in their own words, including D17–D18.
3. Run the commands in the log personally and record their own time spent.
4. Complete the sign-off at the bottom of the session log.
5. Be ready to change a scoring rule or cache policy live; that is stronger evidence of
   ownership than claiming the code was written without AI.
